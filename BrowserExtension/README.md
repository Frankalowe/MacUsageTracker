# Mac Usage Tracker - Companion Browser Extension

This is a lightweight optional extension (Manifest V3) for Brave, Chrome, Edge, and Arc that reports your active website domain to **Mac Usage Tracker** with 100% precision.

---

### Why use this extension?
- **Zero macOS Permission Prompts:** Works immediately without needing AppleEvents / Automation permissions in macOS System Settings.
- **Instant Tab Tracking:** Seamlessly captures active tabs, multiple profiles, and window switching with 0ms delay.
- **Ultra Lightweight:** Only a single background script with zero external dependencies and near-zero memory footprint.

---

### How to Install (Takes 15 seconds)

1. Open your browser:
   - **Brave:** Go to `brave://extensions`
   - **Google Chrome:** Go to `chrome://extensions`
   - **Microsoft Edge:** Go to `edge://extensions`
   - **Arc:** Go to `arc://extensions`
2. Turn **ON** the **Developer mode** toggle (in the top right corner).
3. Click **Load unpacked** (in the top left corner).
4. Select this `BrowserExtension` folder:
   `/Users/franklowe/Documents/antigravity/brave-oppenheimer/BrowserExtension`
5. That's it! As you browse, your active website domains will now be automatically and flawlessly logged in Mac Usage Tracker.
